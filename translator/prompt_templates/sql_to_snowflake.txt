## Rules

1. Set operations, not row loops. A `merge` that changes cardinality is a
   defect even when every value it emits is correct - check the row count
   before and after every join.
2. Outer-join direction is the highest-risk decision in this translation.
   State in a comment which side is preserved and why.
3. Aggregate before you rank. A window function over an un-aggregated frame
   silently produces a different partition.
4. Reproduce NULL semantics: `NULL = NULL` is unknown, not true. A pandas
   merge key of NaN behaves differently from a SQL NULL join key.
5. Preserve ORDER BY exactly. If the ordering is not total, add the tiebreak
   the source relied on and say so.
6. Read CSV input with `dtype=str, keep_default_na=False`, then cast the
   columns you actually compute on. Inference loses leading zeros and turns
   integer keys into floats.

## Available helpers

`equivalence.perl_semantics` is importable and provides exact equivalents for
the Perl behaviours Python does not share. Prefer these over reimplementing:

    perl_split(pattern, value, limit=0)   trailing empties dropped when limit=0
    perl_num(value)                       undef/non-numeric -> 0.0, never NaN
    perl_int(value)                       truncate toward zero
    perl_true(value)                      "" and "0" false; "0.0" and "00" true
    perl_sort(values)                     string sort, Perl's default
    perl_sprintf_f(value, places)         sprintf("%.Nf", ...)
    days_between(from_iso, to_iso)        integer civil-date difference

Read CSV input with `dtype=str, keep_default_na=False` unless you have a
specific reason not to. Letting pandas infer types is how a column of account
numbers becomes floats and loses its leading zeros.

## Rules

1. Preserve behaviour, including behaviour that looks like a bug. If the
   legacy job divides by an observed field count rather than the header width,
   so does the translation. Note it in a comment; do not fix it. Correctness
   changes are a separate, reviewed change - not a side effect of a migration.
2. Never let a value become NaN where Perl would have produced 0. A single NaN
   propagates through every downstream aggregate.
3. State date formats explicitly. Never rely on inference.
4. Preserve output ordering exactly, including Perl's string sort.
5. Comment every place where you deliberately reproduced a Perl-specific
   behaviour, and say which one. A reviewer has four hours per script.
